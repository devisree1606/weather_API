Overview

Weather AI Assistant is a Streamlit application that provides current weather information for a selected city and generates an AI-based weather explanation.

Features

* Enter city name
* Get current temperature
* View humidity and wind speed
* Get AI-based weather explanation

Technologies

* Python
* Streamlit
* Open-Meteo API
* Hugging Face
* Requests

Project Files

app.py
test_token.py
requirements.txt
.env

Run

python -m streamlit run app.py

Security

The Hugging Face access token is stored in the .env file and should not be shared publicly.

Conclusion

This project integrates weather API and AI technology using Python and Streamlit to provide simple and useful weather information.
